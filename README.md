# WebAppTest

A simple client-side database search app. Enter a search term and query a local dataset in-browser.

## Structure

```
WebAppTest/
├── index.html
├── css/styles.css
└── js/scripts.js  
```

## Run

Open `index.html` directly in a browser. No server needed.
